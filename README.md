# Сравнительный анализ методов ML для предсказания популярности новостей

**Цель** — исследовать модели машинного обучения (от kNN до нейросетей) на датасете Online News Popularity, оценить их способность предсказывать количество репостов (регрессия) и бинарную популярность (классификация).

## Данные
- Датасет: UCI Online News Popularity (59 признаков, ~39k статей).
- Целевая переменная: `shares` (количество репостов).
- Для классификации: бинарный признак `is_popular` (70-й перцентиль).

## Методы
| Категория | Модели |
|-----------|--------|
| Базовые | kNN (с фикс. k, с кросс-валидацией, GridSearch) |
| Линейные | Линейная регрессия, Ridge, Lasso, логистическая регрессия |
| SVM | SVR, SVC (с разными ядрами) |
| Деревья | Decision Tree (регрессия/классификация) |
| Ансамбли | Random Forest, Gradient Boosting |
| Нейросети | MLPRegressor, MLPClassifier |

## Результаты (кратко)
### Регрессия (лучший R²)
- **Gradient Boosting**: R² = 0.055, MSE ≈ 29.6M
- Линейные модели (Ridge/Lasso): R² ≈ 0.054
- kNN и SVR дали отрицательный R².

### Классификация (лучшая accuracy)
- **Gradient Boosting**: accuracy = 0.722, recall (популярные) = 0.27
- Логистическая регрессия: accuracy = 0.716
- Все модели страдают от дисбаланса классов (популярные статьи плохо определяются).

## Выводы
- Для регрессии простые модели не справляются с предсказанием точного числа репостов — нужны более сложные фичи или другие подходы.
- Для классификации Gradient Boosting даёт лучшее качество, но проблема дисбаланса остаётся.
- Кросс-валидация и GridSearch улучшают результаты по сравнению с фиксированными параметрами.

## Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Скачать датасет с UCI и положить в `data/OnlineNewsPopularity.csv`
3. Открыть `notebooks/01_full_analysis.ipynb` и выполнить ячейки.
